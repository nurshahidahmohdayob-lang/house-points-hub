# 🏆 House Points Hub

A classroom app for teachers (Year 1–11) to run house points, rewards and class activities.

- **Houses** – live leaderboard, whole-house bonus points, projector mode for the big screen
- **Award** – tap one or many students, pick a reason (Teamwork, Kindness…) or give custom points
- **Activities** – Random Picker, House Quiz Battle, Countdown Timer, Team Maker, Mystery Reward Wheel
- **Rewards** – students spend their own points on rewards (house totals stay the same)
- **History** – full log, undo, CSV export
- **Setup** – houses, bulk-add students, reasons, backup/restore

Data is stored in the teacher's browser (localStorage). Use **Setup → Download backup** to move it to another computer.

Static site – no build step. Deployed on Vercel.
